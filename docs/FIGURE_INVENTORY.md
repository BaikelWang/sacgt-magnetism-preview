# Figure inventory

This collection distinguishes the revised architecture diagram from the historical preview assets retained in the repository. The historical assets are not a substitute for the accepted paper and its Supplementary Information.

## Revised architecture

| File | Description |
|---|---|
| [Figure 1 PDF](../assets/figures/main/figure1.pdf) / [PNG](../assets/figures/main/figure1.png) | Revised SACGT architecture, including cross-attention and feature-wise gated fusion |

The authors assembled Figure 1 in Visio and PowerPoint. The crystal illustration was obtained from the Materials Project entry [mp-865951](https://next-gen.materialsproject.org/materials/mp-865951).

## Historical main-text previews

| File | Description and interpretation |
|---|---|
| [Figure 2](../assets/figures/main/figure2.pdf) | Original predictive evaluation, learning curves, and component comparisons. These are historical results, not the additional revision-stage benchmark. |
| [Figure 3](../assets/figures/main/figure3.pdf) | Historical Ti₂O₃ attention and attribution panels. Site contributions are not independently validated atomic moments. The revised manuscript no longer reports the undefined ±0.05 μB uncertainty range. |
| [Figure 4](../assets/figures/main/figure4.pdf) | Original C2DB screening and the CrS₂H case study. Different screening passes should not be treated as a controlled checkpoint-only robustness experiment. |

The Ti₂O₃ reference is from Materials Project [mp-776655](https://next-gen.materialsproject.org/materials/mp-776655), not a new Ti₂O₃ DFT calculation performed for this study. Figure 3 was drawn by the authors using VESTA and Python.
