# Release status

## Current public companion

The repository provides selected figures, visualization utilities, and citation metadata for the paper accepted in *npj Computational Materials*. The article is not yet online. Except for the revised architecture diagram, the figure collection contains historical previews; it is not the complete accepted-paper figure set.

## Publication metadata

Once the journal publishes the article, the repository can be updated with the verified article URL, DOI, and final bibliographic details. No publication date is announced here.

## Any wider release

A future code or data release would require:

- explicit author approval of the release scope;
- confirmation of institutional and third-party redistribution rights;
- removal of credentials, private records, and infrastructure details;
- tested instructions and a clear distinction between examples and full reproduction;
- an appropriate licence and, if applicable, a verified accessible archive.

This is a list of prerequisites, not a commitment to release the implementation, weights, or datasets. The current access conditions are described in the [access policy](PREPUBLICATION_ACCESS.md).
